# OptiQubo 经典求解界面设计

## 1. 页面定位

经典求解页面用于对导入的 QUBO 问题执行固定的经典状态遍历计算，并输出全局最优能量和对应解。

页面不提供算法选择，不显示求解类型，也不使用“暴力求解”等字样。

## 2. 全局导航

左侧一级菜单：

```text
首页
QUBO 求解
经典求解  ← 当前高亮
结果分析
设置
```

底部保留“帮助”。

## 3. 页面整体布局

页面继续采用与 QUBO 求解一致的三栏结构：

\[
\boxed{\text{左：输入与运行控制}}
\quad
\boxed{\text{中：能量演化与日志}}
\quad
\boxed{\text{右：输出与保存}}
\]

## 4. 左侧参数区

### 4.1 QUBO 文件

控件：

- QUBO 文件路径输入框；
- 文件浏览按钮。

### 4.2 配置文件

控件：

- 配置文件路径输入框；
- 文件浏览按钮；
- `使用导入配置` 复选框。

配置文件可来自光学 QUBO 任务，用于复用同一问题的数据来源与相关配置。经典计算不需要的字段由程序忽略。

### 4.3 问题信息

只读显示：

```text
变量数       20
总状态数     1,048,576
```

其中：

\[
N_{\text{states}}=2^N
\]

不显示算法名称和求解类型。

### 4.4 运行控制

显示：

- 运行进度条；
- 已遍历状态数 / 总状态数；
- 当前状态；
- 开始计算；
- 停止。

示例：

```text
运行进度
████████████░░░░ 68%

712,835 / 1,048,576

当前状态  ● 计算中

[开始计算]
[停止]
```

## 5. 中间主区域

### 5.1 能量演化曲线

显示截至当前已遍历状态所发现的最优能量：

\[
E_{\mathrm{best}}(k)
=
\min_{1\le i\le k}E_i
\]

横轴：

```text
已遍历状态数
```

纵轴：

```text
能量 E
```

曲线名称：

```text
当前最优能量
```

完整计算结束后可增加一条最终参考线：

```text
全局最优能量
```

### 5.2 运行日志

日志内容包括：

- QUBO 文件读取；
- 配置文件读取；
- 变量数；
- 总状态数；
- 经典计算启动；
- 已遍历状态数；
- 当前最优能量；
- 计算完成或停止；
- 异常信息。

页面中不得出现“暴力”“穷举”等文字。

## 6. 右侧运行结果

运行结果 Card 显示：

```text
运行状态
已遍历状态数
当前最优能量
最优状态编号
运行时间
计算速度
预计剩余时间
```

计算完成后：

```text
当前最优能量
```

变为：

```text
全局最优能量
```

## 7. 右侧输入信息

只读显示：

```text
QUBO 文件
配置文件
矩阵维度
变量数
最大值
最小值
总状态数
```

不显示“求解类型”。

## 8. 结果保存

控件：

- 保存路径；
- 浏览按钮；
- 文件名；
- 添加时间戳；
- 自动保存；
- 保存结果。

自动保存关闭时，用户可在查看曲线与结果后手动点击“保存结果”。

## 9. 命名统一

页面标题：

```text
经典求解
```

按钮：

```text
开始计算
停止
```

状态：

```text
空闲
准备中
计算中
已完成
已停止
异常
```

禁止出现：

```text
模拟求解
暴力求解
暴力穷举
求解算法
求解类型
```
