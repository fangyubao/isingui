# OptiQubo 结果分析——对比模式

## 1. 页面定位

该模式用于同时载入两个结果文件，对光学 QUBO 结果、经典求解结果或同类结果进行对比。

## 2. 全局导航

左侧一级菜单：

```text
首页
QUBO 求解
经典求解
结果分析  ← 当前高亮
设置
```

底部保留“帮助”。

## 3. 页面布局

\[
\boxed{\text{左：A/B 文件与对比设置}}
\quad
\boxed{\text{中：A/B 曲线与 Sigma 向量}}
\quad
\boxed{\text{右：A/B 结果与差值}}
\]

## 4. 左侧文件选择

显示：

```text
A 文件（光学 QUBO）
B 文件（经典求解）
启用对比模式
```

以及共有信息：

- QUBO 文件；
- 变量数；
- 显示维度；
- 开始对比。

界面中使用“经典求解”，不使用“暴力求解”。

## 5. 中间曲线

### 5.1 A 曲线

标题：

```text
A：光学 QUBO 能量曲线
```

横轴：

```text
迭代次数
```

### 5.2 B 曲线

标题：

```text
B：经典求解最优能量曲线
```

横轴：

```text
已遍历状态数
```

两张图保持上下排列和相同宽度，不强制共用同一横轴。

## 6. Sigma 向量统一预览

底部统一显示两行：

```text
A：Sigma 向量（前 20 个元素）
B：Sigma 向量（前 20 个元素）
```

两行必须使用完全相同的视觉规则：

- 相同卡片宽度；
- 相同卡片高度；
- 相同索引位置；
- 相同字号；
- `+1` 为蓝色浅底；
- `-1` 为红色浅底；
- 均提供“查看完整”；
- 均可导出 CSV。

若 B 文件保存的是：

\[
x_i\in\{0,1\}
\]

则先转换：

\[
\sigma_i=2x_i-1
\]

再显示，不允许 A 显示 Sigma、B 显示 x。

## 7. 右侧结果 A

显示：

```text
最优能量
最优迭代
运行时间
```

## 8. 右侧结果 B

显示：

```text
全局最优能量
最优状态编号
运行时间
```

## 9. 对比结果

只显示客观数值：

\[
\Delta E=E_A-E_B
\]

\[
Gap=
\frac{|E_A-E_B|}{|E_B|}
\times100\%
\]

以及：

```text
结果文件 A
结果文件 B
备注
```

## 10. 禁止显示

不得显示：

```text
是否达到全局最优
是否达到最优解
达到最优：是 / 否
暴力求解
暴力穷举
```
