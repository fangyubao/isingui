# OptiQubo 设置——设备与系统界面设计

## 界面预览

![设备与系统界面预览](./device-system.jpg)

页面位于“设置 → 设备与系统”，用于 USB 连接、三路设备电源、DAC 电压、三路风扇、三路温度、设备配置与通信日志。

USB 下拉每项只显示：

```text
设备名称 | 端口号 | VID
```

`VID:0x1314` 的设备排在第一项并默认选中。

设备控制包含 DMD、SLM、PD 电源，三路全开/全关，设定电压、DAC 码值和三路风扇 PWM。当前 DAC 直接设置电压，在缺少换算关系时不能标为实际电流。

温度区域显示摄氏温度与趋势图；ADC 原始值放入折叠的详细数据区。设备配置区提供读取设备配置和保存到设备，即时应用与写入 Flash 分开。

USB 原始帧必须与当前固件一致：

```text
TX  FD 15 FE
RX  FD 15 ... FE
```

不得使用与固件不一致的 `AA 55` 示例。
