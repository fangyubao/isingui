# OptiQubo 设置——对齐界面设计

## 1. 页面定位

“对齐”页面位于：

```text
设置 → 对齐
```

用于完成 SLM 与 DMD 的空间位置、缩放比例、旋转角度及有效区域标定。SLM 负责提供稳定的光学调制背景，DMD 负责投影对齐图案；页面中的所有操作均以“投影—采集—分析—应用”为主线，不改变 QUBO 求解页面的布局。

页面采用上下两段式布局：

\[
\boxed{\text{上：对齐测试与实时预览}}
\qquad
\boxed{\text{下：参数结果与配置保存}}
\]

## 2. 导航状态

- 全局一级菜单“设置”高亮；
- 设置二级菜单“对齐”高亮；
- 二级菜单同时显示“标定”和“设备与系统”；
- 顶部栏、左侧栏、底部状态栏与其他设置页面完全一致。

设置二级菜单顺序统一为：

```text
标定
对齐
设备与系统
```

## 3. 上半部分：对齐测试与预览

### 3.1 左侧：测试控制

提供以下控件：

- 对齐模式：十字靶标、棋盘格、点阵三选一；
- DMD 图案尺寸：宽度、高度；
- 图案间距 / 点阵间距；
- 扫描步长：默认 1 px，可选 1 / 2 / 4 / 8 px；
- 采集帧数：用于多帧平均；
- 开始对齐；
- 停止；
- 应用当前参数。

“开始对齐”启动 DMD 图案序列并同步读取 PD 或相机数据；“停止”立即终止序列；“应用当前参数”仅在结果通过校验后可用。

### 3.2 中央：实时对齐预览

中央卡片显示 SLM 与 DMD 的叠加预览：

- 蓝色轮廓：SLM 有效区域；
- 紫色轮廓：DMD 投影区域；
- 绿色十字：当前估计中心；
- 黄色参考线：水平 / 垂直基准线；
- 半透明棋盘格或点阵：当前 DMD 测试图案。

预览区支持缩放、平移和“适应窗口”。右上角显示当前图案编号、采集帧号和帧率。预览只用于观察，不允许直接拖拽修改参数，避免绕过标定结果。

### 3.3 右侧：实时状态

实时显示：

| 项目 | 内容 |
|---|---|
| SLM 状态 | 已连接 / 未连接 |
| DMD 状态 | 已连接 / 未连接 |
| 采集设备 | PD / QCMOS / 相机 |
| 当前中心偏差 | \(\Delta x,\Delta y\) |
| 当前旋转角 | \(\theta\) |
| 当前缩放比例 | \(s_x,s_y\) |
| 对齐置信度 | 0–100% |
| 测试进度 | 进度条与百分比 |

状态颜色沿用全局规范：绿色表示正常，黄色表示待确认，红色表示设备异常或结果超限。

## 4. 下半部分：参数结果与校验

### 4.1 参数结果卡片

对齐分析输出二维仿射变换：

\[
\begin{bmatrix}x_{SLM}\\y_{SLM}\end{bmatrix}
=
\begin{bmatrix}a&b\\c&d\end{bmatrix}
\begin{bmatrix}x_{DMD}\\y_{DMD}\end{bmatrix}
+
\begin{bmatrix}t_x\\t_y\end{bmatrix}
\]

界面同时显示便于工程人员理解的参数：

- 水平偏移 \(\Delta x\)；
- 垂直偏移 \(\Delta y\)；
- 旋转角度 \(\theta\)；
- 水平 / 垂直缩放 \(s_x,s_y\)；
- 有效重叠宽度 / 高度；
- 重叠率；
- 重投影误差 RMSE。

### 4.2 对齐校验

提供“重新计算”和“校验当前配置”两个按钮。校验结果分为：

- 通过：重叠率、RMSE 和偏差均在配置阈值内；
- 警告：可继续使用，但建议重新标定；
- 失败：禁止应用并提示检查光路、焦距和设备连接。

推荐默认阈值：重叠率 ≥ 95%，中心偏差 ≤ 2 px，RMSE ≤ 1.5 px。阈值可在高级设置中修改。

### 4.3 配置文件操作

右下角提供：

- 导入配置；
- 保存配置；
- 另存为；
- 恢复上次已应用配置。

推荐 JSON 格式：

```json
{
  "offset": {"x": 0.0, "y": 0.0},
  "rotation_deg": 0.0,
  "scale": {"x": 1.0, "y": 1.0},
  "overlap": {"width": 0, "height": 0, "ratio": 0.0},
  "rmse_px": 0.0,
  "pattern": "crosshair",
  "timestamp": "2026-09-15T00:00:00Z"
}
```

保存前显示摘要确认；应用新配置前保留旧配置，以便恢复。

## 5. 交互与异常规则

1. 未检测到 SLM、DMD 或采集设备时，“开始对齐”置灰，并在状态卡片中指出缺失设备。
2. 对齐运行期间锁定图案尺寸、步长和设备选择，防止序列中途改变条件。
3. 切换页面或关闭窗口时，若存在未保存结果，弹出“保存 / 放弃 / 取消”确认框。
4. 应用配置后，在底部状态栏记录“对齐参数已应用”和时间戳。
5. 暗色主题仅改变背景、文字和卡片颜色，预览中的蓝、紫、绿、黄辅助色保持足够对比度。
