# OptiQubo 设置——对齐界面设计

## 1. 页面定位

“对齐”页面位于：

```text
设置 → 对齐
```

该页面的核心不是抽象的光学叠加图，而是把 SLM 与 DMD 的像素对应关系直接呈现给测试人员：左侧显示 SLM 像素方格矩阵，右侧显示 DMD 像素方格矩阵。每个方格代表一个逻辑像素，方格的横向、纵向数量与当前设备分辨率一致；在大分辨率下使用缩放、平移和视口渲染保持可操作性。实现上采用 Canvas/WebGL 分块渲染（例如 256×256 tile），缩略视图按块聚合，放大到 1:1 时显示真实单像素方格，点击始终反算到真实行列坐标，不用少量示意格冒充 4K 网格。

页面区分两类状态：

1. **标定前 / 无标定文件**：所有像素方格显示为灰白色，表示“无效或未知”，不得把它们误认为有效光学区域；
2. **加载标定文件或完成标定后**：有效像素显示高亮色，无效像素仍保持灰白色；选中的像素使用更醒目的颜色并闪烁，同时在另一侧高亮其对应像素。文件来源必须明确标记为“出厂”“上次应用”或“用户导入”。

整个页面分为“像素对应调试区”和“硬件标定结果区”。矩阵选择与闪烁联动属于软件可视化，不需要实时驱动 SLM、DMD 或相机；只有点击“一键标定”后，才进入硬件联动流程。

## 2. 导航状态

- 全局一级菜单“设置”高亮；
- 设置二级菜单“对齐”高亮；
- 二级菜单顺序固定为：

```text
标定
对齐
设备与系统
```

- 顶部栏、左侧栏和底部状态栏与“标定”“设备与系统”页面完全一致。

## 3. 顶部工具栏：配置与一键标定

顶部工具栏提供：

- SLM 型号 / 分辨率：例如 `4096 × 2160`；
- DMD 型号 / 分辨率：例如 `4000 × 2464`；
- 当前标定文件：文件名、版本、生成时间；
- 加载标定文件；
- 一键标定；
- 一键验证；
- 重新加载当前配置；
- 视图复位。

默认启动逻辑：

- 存在默认标定文件：自动加载，矩阵按文件标记有效与无效区域，并显示“已加载标定文件”；
- 不存在标定文件：矩阵全部显示灰白色，页面显示“未标定”，一键标定按钮保持可用；
- 标定运行期间锁定分辨率、设备配置和矩阵手动编辑，避免标定过程中产生不一致状态。

“一键标定”执行“投影标定图案 → 采集响应 → 特征提取 → 建立映射 → 拟合 → 生成标定文件 → 校验”的完整流程；“一键验证”只复测当前已加载 / 已应用的映射，不重新生成拟合参数，也不覆盖标定文件。

## 4. 核心区域：SLM / DMD 双像素矩阵

### 4.1 SLM 像素矩阵

左侧卡片标题为“SLM 像素矩阵”，显示：

- 分辨率和当前视口范围；
- 当前选中坐标 `(x, y)`、线性索引和有效状态；
- 缩放比例、适应窗口、放大 / 缩小、平移；
- 坐标搜索框，可输入像素坐标或线性索引定位。

矩阵显示规则：

- 有效像素：蓝色或青色高亮；
- 无效像素：灰白色；
- 当前选中像素：橙色边框 + 闪烁填充；
- 当前选中像素的邻域：浅蓝色辅助框，便于检查边界；
- 鼠标悬停显示像素坐标、有效状态、对应 DMD 坐标和误差。

有效掩膜的判定为：几何映射落在目标边界内、标定残差未超阈值且采集信号质量达标。越界、残差超限、低信号、饱和和遮挡分别记录为无效原因，可在筛选器中单独查看。

### 4.2 DMD 像素矩阵

右侧卡片标题为“DMD 像素矩阵”，规则与 SLM 矩阵相同，但使用紫色作为 DMD 的设备识别色：

- 有效像素：紫色或靛色高亮；
- 无效像素：灰白色；
- 当前对应像素：橙色边框 + 闪烁填充；
- 悬停显示 DMD 坐标、SLM 对应坐标、映射误差和置信度。

矩阵不直接表示当前光强，也不代表硬件正在刷新；它是标定文件和映射计算结果的可视化视图。

### 4.3 双向选择联动

- 在 SLM 矩阵选中一个有效格子，DMD 矩阵中对应格子同步高亮并闪烁；
- 在 DMD 矩阵选中一个有效格子，SLM 矩阵中对应格子同步高亮并闪烁；
- 若映射不存在或像素无效，另一侧显示“无对应像素”，不强行高亮；
- 闪烁频率可设置为 1 Hz、2 Hz、4 Hz 或关闭；
- 支持“锁定当前选择”，便于测试人员移动鼠标观察邻域而不改变当前对应关系；
- 支持“显示映射线 / 隐藏映射线”，在两侧之间绘制轻量连接指示，不遮挡矩阵。

矩阵中央显示当前对应关系摘要：

```text
SLM (x=1024, y=512)  ↔  DMD (x=987, y=604)
偏移：Δx=-37 px，Δy=+92 px    映射误差：0.82 px
```

由于两块器件分辨率可能不同，映射结果不强制一对一：一个 SLM 像素可以对应一个或多个 DMD 像素，反向也可能成立。详情区同时显示浮点坐标、最近整数像素、对应像素数量和局部误差。

### 4.4 矩阵面积与精准点选优先级

双矩阵是页面的绝对主体，不设置固定宽度的中央详情面板，不绘制遮挡像素的长连线。SLM 与 DMD 各占主内容区约一半宽度，矩阵画布占页面可用高度的主要部分；对应关系摘要放在各自矩阵标题和底部选中状态行中。

为保证测试人员能够精准选中某个像素，矩阵必须支持：

- 鼠标滚轮以指针为中心缩放；
- 拖拽平移和“适应窗口”；
- 2× / 4× / 8× 像素级放大；
- 输入 `(x, y)` 或线性索引后自动定位；
- 键盘方向键逐像素移动；
- 指针附近 3×3 / 5×5 局部放大镜；
- 点击后固定显示坐标、有效状态、对应坐标、误差和置信度。

概览视图可以按 tile 聚合，但必须明确标注“概览聚合”；放大视图显示真实方格，不能用几十个示意格代替 4K 逻辑矩阵。矩阵保持设备宽高比，不能为了填满卡片而拉伸。

## 5. 像素状态图例与调试操作

矩阵下方固定显示图例：

| 状态 | 颜色 | 含义 |
|---|---|---|
| 有效 | 蓝色 / 紫色 | 标定文件中通过有效性判断的像素 |
| 无效 | 灰白色 | 未覆盖、遮挡、响应不足或标定失败 |
| 当前选择 | 橙色闪烁 | 当前正在检查的像素 |
| 对应映射 | 橙色描边 / 连接线 | 另一侧被联动定位的像素 |
| 异常 | 红色 | 映射缺失、误差超阈值或数据异常 |

后端建议区分 `device_valid`（本设备像素自身可用）与 `pair_valid`（存在满足阈值的另一侧对应像素）。只有两者都满足时才使用“有效”高亮；单侧可用但没有有效配对的像素保持灰白底色，并叠加黄色角标或斜纹提示。

建议提供以下纯软件调试操作：

- 只显示有效像素、只显示无效像素或只显示异常像素；
- 显示边界 / 有效区域轮廓；
- 显示映射误差热力；
- 显示坐标、行列号和线性索引；
- 导出当前视口截图；
- 导出像素映射表 CSV / JSON、有效掩膜 PNG / 二进制文件。

手动修改有效性应默认关闭；如确有需要，进入“调试编辑模式”后才能手动标记有效 / 无效，并要求另存为新标定文件，不覆盖原始文件。

## 6. 一键标定与结果区

### 6.1 标定流程卡片

一键标定启动后显示阶段进度：

```text
设备检查 → 投影标定图案 → 采集响应 → 特征提取
→ 拟合映射 → 生成有效掩膜 → 质量校验 → 待应用
```

结果区显示：

- 当前阶段和总体进度；
- 已处理像素 / 总像素；
- 有效像素数、无效像素数和有效率；
- 可中止标定；
- 失败阶段、错误原因和建议处理方式；
- 原始数据是否完整、是否允许生成标定文件。

标定结果先进入“草稿 / 待应用”状态，不能直接覆盖当前已应用配置。质量达标后提供“应用并保存”，并保留旧版本用于回滚。

### 6.2 拟合与质量信息

标定完成后显示：

- 映射模型：平移、相似变换、仿射或单应性；
- 拟合参数矩阵；
- X / Y 方向偏移；
- 旋转角度、缩放比例、剪切 / 透视项；
- 有效重叠宽度、高度、面积和重叠率；
- SLM / DMD 有效像素数、配对数和有效率；
- 拟合 RMSE、最大误差、95% 分位误差；
- 内点比例、置信度、异常点数量；
- 有效边界、多连通区域和孔洞数量；
- 标定时间、设备序列号、采集设备和温度。

二维映射可表示为：

\[
\begin{bmatrix}x_{SLM}\\y_{SLM}\\1\end{bmatrix}
=H\begin{bmatrix}x_{DMD}\\y_{DMD}\\1\end{bmatrix}
\]

当采用仿射模型时，界面同时显示工程人员更容易理解的参数：\(\Delta x\)、\(\Delta y\)、\(\theta\)、\(s_x\)、\(s_y\) 和 RMSE。

全局单应性用于描述整体位置关系；当存在镜头畸变、局部形变或局部遮挡时，标定文件还应允许附加分块位移场 / 局部 LUT 和残差图，矩阵视图按局部结果显示，不把整个区域强行判定为有效。

另外必须显式显示坐标原点、行列方向、转置状态、水平 / 垂直翻转状态，避免图像坐标与光学坐标混淆。

### 6.3 校验与文件管理

提供三个容易区分的动作：

- **校验当前标定**：不重新采集，只依据当前文件重新计算统计量；
- **一键验证**：重新驱动设备采集验证数据，验证当前映射在硬件上的实际效果，但不修改拟合参数和标定文件；
- **一键标定**：重新采集并生成新的拟合结果和有效掩膜。

一键验证完成后显示独立的验证结果：

- 当前使用的标定文件版本和来源；
- 实测 \(\Delta x\)、\(\Delta y\)、\(\theta\)、缩放比例；
- 实测重叠率、RMSE、P95、最大误差、置信度；
- 与标定文件中拟合值的差异；
- 通过 / 警告 / 失败及具体超阈值项目；
- 验证时间、采集帧数、温度和设备序列号。

验证结果只写入验证日志，不覆盖当前标定文件；如需改变映射，必须显式执行“一键标定”并经过“应用并保存”。

同时提供：

- 保存为新版本；
- 恢复上一个版本；
- 导入 / 导出标定文件；
- 对比两个标定文件的偏移、有效率和误差；
- 查看标定日志和原始采集数据位置；
- 导出诊断报告。

推荐默认判定阈值：

- 有效重叠率 ≥ 95%；
- 中心偏差 ≤ 2 px；
- RMSE ≤ 1.5 px；
- 95% 分位误差 ≤ 3 px；
- 异常点比例 ≤ 5%。

阈值应允许在高级设置中修改，但修改必须记录在标定日志中。

## 7. 设备联动边界与状态机

为了避免测试人员误解，界面必须显式区分：

- **矩阵选择 / 闪烁 / 对应关系查看**：纯软件操作，不驱动任何硬件；
- **一键标定 / 硬件复测**：驱动 DMD 投影、SLM 配置和采集设备；
- **加载标定文件**：只更新软件矩阵和参数，不自动刷新硬件；
- **应用标定参数**：需要二次确认，确认后才把映射参数交给运行时求解链路。

页面状态建议明确显示：

```text
未加载 → 出厂标定已加载 → 标定中 → 新结果待应用
       ↘ 配置不兼容 / 标定失败       → 已校验 → 已应用
                              └→ 验证中 → 验证通过 / 验证警告 / 验证失败
```

标定完成但未点击“应用”时，底部状态栏应显示“已生成标定文件，尚未应用到运行时”。一键验证期间矩阵保持可浏览但标记为“验证进行中”，验证失败不改变当前运行时版本。文件与设备型号、序列号、分辨率不匹配时不得静默套用，应显示“配置不兼容”。

## 8. 建议补充的测试功能

为满足现场调试，建议增加：

1. **坐标搜索与单元测试**：输入任意 SLM / DMD 坐标，立即定位另一侧对应单元，并显示映射误差；
2. **ROI 测试 / 局部重标定**：只对选定矩形区域运行，减少首次调试时间；
3. **映射误差热力图**：快速发现边缘畸变、局部遮挡和异常区域；
4. **标定文件版本管理**：保留旧版本、比较差异、支持回滚；
5. **硬件安全互锁**：设备未连接、采集帧不足或温度异常时禁止开始标定；
6. **日志与原始数据回放**：允许脱离硬件复盘一次标定，验证算法和界面显示；
7. **导出报告**：导出矩阵有效性、拟合参数、误差统计和标定时间，方便写入测试报告。
8. **离线回放 / 仿真模式**：只读取标定文件或原始采集数据，验证矩阵联动而不驱动设备；
9. **重复性测试**：连续执行 N 次硬件复测，统计 \(\Delta x\)、\(\Delta y\)、\(\theta\) 的均值和标准差；
10. **人工角点校正**：自动特征提取失败时允许少量人工配对，但只能生成草稿，不能覆盖出厂文件。

## 9. 推荐标定文件契约

4K 级掩膜不建议保存为巨大的 JSON 像素数组，建议采用分块 bitset / RLE，并将映射和元数据分开保存：

```json
{
  "schema_version": 1,
  "slm": {"model": "...", "serial": "...", "width": 4096, "height": 2160},
  "dmd": {"model": "...", "serial": "...", "width": 4000, "height": 2464},
  "orientation": {"transpose": false, "flip_x": false, "flip_y": false},
  "transform": {"type": "homography", "matrix": [[1,0,0],[0,1,0],[0,0,1]], "origin": "top_left"},
  "masks": {"slm": "slm.mask.rle", "dmd": "dmd.mask.rle", "valid_threshold": 0.8},
  "metrics": {"overlap_ratio": 0.0, "rmse_px": 0.0, "p95_px": 0.0, "max_px": 0.0, "confidence": 0.0},
  "acquisition": {"detector": "QCMOS", "frames": 0, "timestamp": "2026-09-15T00:00:00Z"},
  "status": {"quality": "draft", "applied_at": null}
}
```
