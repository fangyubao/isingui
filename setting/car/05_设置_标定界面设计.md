# OptiQubo 设置——标定界面设计

## 1. 页面定位

标定页面位于：

```text
设置 → 标定
```

页面包含上下两个功能区：

\[
\boxed{\text{上：灰度—光强响应测试}}
\]

\[
\boxed{\text{下：256 点灰度 LUT 映射}}
\]

不使用 Tab。

---

## 2. 导航状态

- 全局一级菜单“设置”高亮；
- 设置二级菜单“标定”高亮；
- 二级菜单同时显示“设备与系统”。

---

## 3. 上半部分：光强响应测试

### 3.1 测试流程

依次投影：

\[
G=0,1,2,\ldots,255
\]

读取对应光强：

\[
(G_i,I_i)
\]

每个灰度可重复采样 \(M\) 次。

### 3.2 参数控件

- 灰度起点；
- 灰度终点；
- 单点采样次数；
- 采样间隔；
- 开始测试；
- 停止；
- 测试进度。

### 3.3 响应图

横轴：

```text
灰度值 G
```

纵轴：

```text
光强 I
```

显示：

- 实测点；
- 线性拟合；
- 可选理论线性参考。

### 3.4 测试结果

显示：

- 线性拟合度 \(R^2\)；
- 拟合方程；
- 平均标准差；
- 最大标准差；
- 平均波动率 CV；
- 最大波动率 CV；
- 当前灰度；
- 当前光强。

拟合度：

\[
R^2
=
1-
\frac{\sum_i(I_i-\hat I_i)^2}
{\sum_i(I_i-\bar I)^2}
\]

波动率：

\[
CV_i=
\frac{\sigma_i}{\bar I_i}\times100\%
\]

## 4. 下半部分：灰度映射 LUT

### 4.1 映射关系

默认：

\[
LUT[i]=i
\]

实际输出：

\[
G_{\mathrm{project}}
=
LUT[G_{\mathrm{input}}]
\]

通过修改 LUT，可人为实现非线性投影。

### 4.2 下半区布局

\[
\boxed{\text{左：快速定位}}
\quad
\boxed{\text{中：LUT 表}}
\quad
\boxed{\text{右：LUT 曲线与文件操作}}
\]

### 4.3 快速定位

控件：

- 序号输入框；
- 跳转；
- 当前序号；
- 输入灰度；
- 投影灰度；
- 应用修改。

序号范围：

\[
0\le index\le255
\]

### 4.4 LUT 表

固定 256 行：

| 序号 | 输入灰度 | 投影灰度 |
|---:|---:|---:|
| 0 | 0 | 0 |
| 1 | 1 | 0 |
| ... | ... | ... |
| 255 | 255 | 255 |

权限：

- 序号：只读；
- 输入灰度：只读；
- 投影灰度：可编辑。

范围：

\[
0\le G_{\mathrm{project}}\le255
\]

表格使用固定高度与内部纵向滚动条。

### 4.5 LUT 曲线

横轴：

\[
G_{\mathrm{input}}
\]

纵轴：

\[
G_{\mathrm{project}}
\]

显示：

- 当前 LUT；
- 线性参考。

编辑表格后曲线实时更新。

### 4.6 CSV 操作

提供：

- 读取 CSV；
- 保存 CSV；
- 恢复线性映射。

推荐格式：

```csv
index,input_gray,project_gray
0,0,0
1,1,0
...
255,255,255
```

恢复线性：

\[
LUT[i]=i
\]

恢复前建议二次确认。
