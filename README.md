## 统一约束

- “模拟求解”统一命名为“经典求解”。
- 页面不使用“暴力求解”“暴力穷举”“经典暴力”等字样。
- Sigma 始终为一维向量，统一使用索引 + `+1 / -1` 卡片显示。
- 结果分析不显示“是否达到全局最优”等主观判定。
- 对比模式只有在 QUBO 文件、矩阵维度、变量数及矩阵哈希一致时，才允许计算能量差与 Gap。
- 经典求解运行中使用“当前最优能量”；只有完整遍历后才能使用“全局最优能量”。
- USB 原始帧以固件当前协议 `0xFD ... 0xFE` 为准。
