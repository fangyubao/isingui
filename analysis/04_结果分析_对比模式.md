# OptiQubo 结果分析——对比模式

## 界面预览

![结果对比模式](./comparison.jpg)

只有以下字段全部一致时，才允许计算能量差与 Gap：

```text
QUBO 任务 ID 或文件
矩阵维度
变量数
矩阵内容哈希
```

建议结果文件保存 `qubo_hash`、`matrix_shape` 和 `variable_count`。

A 为光学 QUBO 能量曲线，横轴为迭代次数；B 为经典求解最优能量曲线，横轴为已遍历状态数。两张图上下排列。

A、B 均使用相同的 Sigma 向量卡片组件。B 若保存的是 x 向量，先转换为 Sigma。

只显示客观数值：

\[
\Delta E=E_A-E_B
\]

\[
Gap=\frac{|E_A-E_B|}{|E_B|}\times100\%
\]

不显示“是否达到全局最优”等判定。
