# OptiQubo 结果分析——光学 QUBO 结果

## 界面预览

![光学 QUBO 结果分析](./optical.jpg)

顶部页面标题必须为“结果分析”。结果文件路径与原始 QUBO 文件分开显示，例如：

```text
结果文件：D:/results/optical_run_001.json
QUBO 文件：qubo_example.txt
```

## Sigma 统一视图

显示“Sigma 向量预览”和前 20 个元素：`+1` 蓝色浅底、`-1` 红色浅底、索引位于卡片上方，并提供查看完整与导出 CSV。Sigma 是一维向量，不使用矩阵热力图。

不显示“是否达到全局最优”“是否达到最优解”。
