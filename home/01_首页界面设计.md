# OptiQubo 首页界面设计

## 界面预览

![首页界面预览](./home.jpg)

首页展示系统概览、最近任务、快速入口、设备状态摘要和最近结果，只承担查看与跳转。

## 快速入口

```text
QUBO 求解
经典求解
打开结果
设置
```

## 设备状态

USB 下拉项只显示：

```text
设备名称 | 端口号 | VID
```

`VID:0x1314` 的设备优先排列并默认选中。连接后显示 DMD、SLM、PD 电源状态与三路温度；首页不提供电源、风扇或 DAC 控制，“查看设备详情”进入“设置 → 设备与系统”。

## 最近结果

表格字段为文件名、类型、变量数、最优能量、时间和状态；类型统一使用“光学 QUBO”“经典求解”“标定”。
