# OptiQubo 首页界面设计

## 1. 页面定位

首页用于展示系统总览、最近任务、快速入口、设备连接摘要和最近结果。

首页只负责“查看与跳转”，不承担复杂参数配置和硬件控制。

---

## 2. 全局导航

左侧一级菜单：

```text
首页  ← 当前高亮
QUBO 求解
经典求解
结果分析
设置
```

底部保留“帮助”。

---

## 3. 页面结构

```text
首页
│
├── 系统概览
├── 最近任务
├── 快速开始
├── 设备状态
└── 最近结果
```

总体布局：

\[
\boxed{\text{顶部：系统概览}}
\]

\[
\boxed{\text{左：最近任务}}
\qquad
\boxed{\text{右：快速开始与设备状态}}
\]

\[
\boxed{\text{底部：最近结果}}
\]

---

## 4. 系统概览

系统概览横跨主工作区顶部，显示：

- 系统状态；
- 设备连接状态；
- 固件版本；
- 设备配置状态；
- 当前任务；
- 系统健康状态。

不显示“最高温度”。

示例：

```text
系统状态      ● 已就绪
设备连接      ● 已连接
固件版本      1.5 / IsingPower CTROL
设备配置      ● 已同步
当前任务      空闲
系统健康      ● 一切正常
```

---

## 5. 最近任务

### 5.1 无运行任务

显示最近一次完成任务：

- 任务名称；
- QUBO 文件；
- 变量数；
- 最优能量；
- 运行时间；
- 完成时间；
- 能量演化缩略图；
- 查看详细结果。

示例：

```text
任务名称      光学 QUBO 求解
QUBO 文件     qubo_example.txt
变量数        500
最优能量      -18,093.21
运行时间      00:00:23
完成时间      2025-09-09 14:32:18
```

### 5.2 有运行任务

显示：

```text
当前任务
运行状态
运行进度
当前能量
最优能量
运行时间
```

首页不提供“停止”按钮，点击“查看运行详情”跳转至对应求解页面。

---

## 6. 快速开始

快速入口固定为：

```text
QUBO 求解
经典求解
打开结果
设置
```

布局建议：

```text
[ QUBO 求解 ]    [ 经典求解 ]

[ 打开结果 ]     [ 设置 ]
```

不再提供“标定”或“设备与系统”的独立快捷入口，它们统一进入“设置”。

### 6.1 打开结果

点击后：

1. 选择结果文件；
2. 跳转到结果分析；
3. 自动加载文件。

### 6.2 设置

点击后进入设置页面，并显示设置二级菜单：

```text
标定
设备与系统
```

---

## 7. 设备状态

### 7.1 设备选择

设备状态 Card 顶部提供 USB 设备下拉框。

每项仅显示：

```text
设备名称 | 端口号 | VID
```

示例：

```text
IsingPower CTROL | COM7 | VID:0x1314
USB Serial Device | COM4 | VID:0x0483
```

其中 `VID:0x1314` 的设备：

- 排在第一项；
- 默认选中。

### 7.2 连接操作

控件：

- 设备下拉框；
- 刷新；
- 连接；
- 断开；
- 连接状态。

### 7.3 状态摘要

连接成功后显示：

```text
DMD 电源      ● 已开启
SLM 电源      ● 已开启
PD 电源       ● 已开启

NTC 1         32.6 ℃  ● 正常
NTC 2         35.2 ℃  ● 正常
NTC 3         41.8 ℃  ● 偏高
```

首页只显示状态，不提供电源开关、风扇和 DAC 控件。

### 7.4 设备详情

按钮：

```text
查看设备详情
```

点击后进入：

```text
设置 → 设备与系统
```

首页与设置页共用同一个全局 USB 会话。

---

## 8. 最近结果

显示最近 3～5 个已保存结果。

字段：

| 字段 | 说明 |
|---|---|
| 文件名 | 结果文件名 |
| 类型 | 光学 QUBO / 经典求解 / 标定 |
| 变量数 | \(N\) |
| 最优能量 | 最优或全局最优能量 |
| 时间 | 完成或保存时间 |
| 状态 | 已完成 / 已停止 / 异常 |

操作：

```text
打开选中结果
查看全部
```

---

## 9. 首页功能边界

首页不提供：

- QUBO 参数编辑；
- 经典计算参数编辑；
- 标定操作；
- LUT 编辑；
- 电源控制；
- 风扇控制；
- DAC 设置；
- 完整结果分析；
- USB 原始帧日志。

---

## 10. 空状态

### 未连接设备

```text
设备未连接
请选择 USB 设备并建立连接
```

### 无历史任务

```text
暂无任务记录
```

### 无保存结果

```text
暂无已保存结果
```
